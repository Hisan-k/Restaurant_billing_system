Restaurant Billing System
A Restaurant Billing System developed as part of the Database Management Systems (DBMS) course project. The application is designed to manage restaurant orders, generate bills, and store data using a MySQL database.
Features:
  Menu display and order management
  Automatic bill generation
  User-friendly graphical interface using Tkinter
  Database connectivity using MySQL
  Efficient storage and retrieval of restaurant data
  
Technologies Used:
  Python
  Tkinter
  MySQL
